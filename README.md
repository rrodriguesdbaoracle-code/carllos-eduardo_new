# Carllos Eduardo — site oficial

Cópia dos arquivos do site publicado, com HTML, CSS, JavaScript, fotos, logo e vídeo. Não exige instalação ou compilação.

## Publicar no GitHub Pages

1. Crie um repositório público chamado `carllos-eduardo`.
2. Extraia o ZIP no computador.
3. No repositório, use **Add file → Upload files** e envie o conteúdo extraído, incluindo a pasta `assets`. Não envie apenas o ZIP.
4. O arquivo `index.html` deve ficar na raiz do repositório.
5. Confirme o envio em **Commit changes**.
6. Abra **Settings → Pages**. Em **Source**, escolha **Deploy from a branch**.
7. Selecione a branch **main**, a pasta **/(root)** e clique em **Save**.
8. Aguarde o GitHub informar o endereço publicado.

Endereço esperado: `https://SEU-USUARIO.github.io/carllos-eduardo/`.

Mantenha os nomes dos arquivos e a pasta `assets` para preservar as imagens e o vídeo.
